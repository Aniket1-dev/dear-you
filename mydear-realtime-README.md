# Mydear realtime enhancement

The active app entry point is now `index.html` for Mydear. Realtime chat is implemented in `chat.html` using Firestore listeners, presence and typing helpers in `assets/js/chat-realtime.js`.

Trust & safety entry points: `kyc.html`, `verification.html`, `verification-badge.html`, `safety-center.html`.

Admin entry points: `admin-dashboard.html`, `admin-kyc.html`, `admin-verification.html`.
