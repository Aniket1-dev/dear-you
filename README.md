# Mydear — Dating App

The repository is now centered on **Mydear**, not HomeSync.

The Mydear build includes the expanded dating-app UI, profiles, discovery, matching, real-time chat, KYC, verification badges, safety tools and a full admin portal.

## Core features

- Profile creation/editing, photos, interests and lifestyle
- Discovery, likes, passes, super likes and matches
- Real-time Firestore chat
- Online/offline presence and typing indicators
- Message read state and reactions
- Photo sharing in conversations
- Date planning and private moments
- KYC, identity, phone, email and age verification flows
- Verification badge application/status
- Reports, blocking, unmatch, appeals and safety center
- Subscriptions, billing, invoices and refunds UI
- Admin dashboard, users, KYC, verification, moderation, analytics, billing, roles and audit logs
